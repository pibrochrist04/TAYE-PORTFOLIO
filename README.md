## À propos du site

Le portfolio est un site web statique multipage. Il présente mon parcours, mes compétences, mes projets et mon CV dans une interface claire et responsive.

- **Structure :** HTML5, avec une page par rubrique.
- **Styles et interactions :** CSS et JavaScript vanilla.
- **Présentation :** fond crème et blanc, titres serif, animations et navigation adaptée aux écrans d'ordinateur, de tablette et de téléphone.
- **Navigation :** liens entre les pages, menu mobile, liens sociaux et filtres de projets.
- **Hébergement :** Netlify.

## Lancer le site en local

1. Télécharger ou cloner le dossier du projet.
2. Ouvrir `index.html` dans un navigateur, ou lancer un serveur local depuis la racine du projet (par exemple avec l'extension Live Server de VS Code).

Les liens vers les pages et les ressources sont relatifs, ce qui permet de déployer le site sur un hébergement statique comme Netlify ou GitHub Pages.
