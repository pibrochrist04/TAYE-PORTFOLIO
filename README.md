🛠️ Comment le portfolio a été créé

Le portfolio est un site web statique, en une seule page, conçu pour présenter mon parcours, mes compétences et mes projets de façon simple et rapide à charger.

Structure et contenu : HTML
Mise en forme : CSS (design sobre, fond clair, typographie soignée, navigation fluide par ancres)
Responsive : le site s'adapte aux écrans d'ordinateur, de tablette et de téléphone
Hébergement et déploiement : Netlify, qui publie le site en ligne et le met à jour à chaque nouvelle version
